# Eingereichte Daten

Hier werden eingereichte Dateien unverändert abgelegt, sobald das Bildungsbüro sie freigegeben hat
(Dateiname: `JJJJ-MM-TT_kurzbeschreibung.<endung>`, dazu die Nummer des GitHub-Formulars im Commit).
Eingearbeitet werden sie in die Dateien unter `sozialraum/daten/`; Ablauf in `werkzeuge/sozialraum/ANLEITUNG.md`.
